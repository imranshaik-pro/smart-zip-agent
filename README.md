# 📦 Smart Zip Agent

A Python script that automatically packs files into multiple ZIP archives, ensuring no single archive exceeds your specified size limit.

## 🚀 Features
- Pack files into multiple ZIPs under a chosen size limit.
- Terminal-based (works on servers and headless machines).
- Handles large folders efficiently.

## 🛠️ How to Run
1. Clone the repo: `git clone git@github.com:imranshaik-pro/smart-zip-agent.git`
2. Navigate to the folder: `cd smart-zip-agent`
3. Run: `python3 smart_zip.py`
4. Enter the folder path and size limit when prompted.
